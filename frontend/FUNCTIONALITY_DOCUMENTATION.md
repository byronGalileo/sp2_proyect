# Application Functionality Documentation

This document outlines the functionalities of the monitoring application.

## 1. Dashboard (`/home`)

The main dashboard provides a high-level overview of the monitored systems.

**Screen:** `lib/app/features/dashboard/views/screens/monitoring_dashboard_screen.dart`

### Actions:

*   **View System Statistics:**
    *   Displays the number of **Active Hosts**.
    *   Displays the number of **Inactive Hosts**.
    *   Displays the number of **Inactive Services**.
*   **View Logs Chart:**
    *   Shows a chart of log activity over a selected period.
*   **Filter by Time Period:**
    *   Allows filtering the logs chart by different time ranges (6h, 12h, 24h, 2d, 7d).
*   **Refresh Data:**
    *   A refresh button allows updating the dashboard data on demand.

## 2. Host Management (`/services/hosts`)

This section allows for the management of host machines.

**Screen:** `lib/app/features/hosts/views/screens/hosts_screen.dart`

### Actions:

*   **List Hosts:**
    *   Displays a list of all configured hosts, either as cards (mobile) or in a table (desktop).
*   **Add a New Host:**
    *   A dialog allows creating a new host with details like hostname, IP address, environment, and region.
*   **Edit an Existing Host:**
    *   Allows modification of an existing host's details.
*   **Delete a Host:**
    *   Removes a host and its associated services.
*   **Filter Hosts:**
    *   Hosts can be filtered by **environment**, **region**, and **status** (active, inactive, maintenance).
*   **Pagination:**
    *   The list of hosts is paginated for better performance.
*   **Add Service to Host:**
    *   Provides a shortcut to add a new managed service directly to a specific host.
*   **Generate Configuration:**
    *   Generates a configuration for a specific host.
*   **Start/Stop Execution:**
    *   Allows starting and stopping the monitoring agent on a host.

## 3. Managed Services (`/services/managed-services`)

This section is for managing the services that run on the hosts.

**Screen:** `lib/app/features/managed_services/views/screens/managed_services_screen.dart`

### Actions:

*   **List Services:**
    *   Displays a list of all managed services. The view can be filtered to show services for a specific host.
*   **Add a New Service:**
    *   A dialog allows adding a new service to a host.
*   **Edit a Service:**
    *   Allows modification of an existing service's configuration.
*   **Delete a Service:**
    *   Removes a managed service.
*   **Filter Services:**
    *   Services can be filtered by **host**, **service name**, **environment**, **region**, and **status** (running, stopped, error, unknown).
*   **View Service Logs:**
    *   Navigates to the Logs screen, pre-filtered for the selected service.
*   **Pagination:**
    *   The list of services is paginated.

## 4. Services Status (`/monitoring/services-status`)

This screen provides a real-time overview of the status of all services.

**Screen:** `lib/app/features/monitoring/views/screens/services_status_screen.dart`

### Actions:

*   **View Service Statistics:**
    *   Shows total number of services, total logs, and total unsent logs.
*   **List Service Statuses:**
    *   Displays a table with the status of each service, including its latest log level, log counts, and last update time.
*   **View Service Logs:**
    *   A button on each row navigates to the logs screen for that specific service.
*   **Refresh Status:**
    *   The data can be refreshed manually.

## 5. Logs (`/monitoring/logs`)

This screen provides a detailed view of the logs generated by the services.

**Screen:** `lib/app/features/monitoring/views/screens/logs_screen.dart`

### Actions:

*   **View Logs:**
    *   Displays logs in a paginated table.
*   **Filter Logs:**
    *   Logs can be filtered by **service**, **log level** (e.g., ERROR, WARNING, INFO), **time range**, and a **fetch limit**.
*   **Pagination:**
    *   The log view is paginated, and the number of rows per page can be adjusted.

## 6. User Management (`/admin/users`)

This section is for managing user accounts.

**Screen:** `lib/app/features/users/views/screens/users_screen.dart`

### Actions:

*   **List Users:**
    *   Displays a list of all users.
*   **Add a New User:**
    *   A dialog allows creating a new user with their details.
*   **Edit a User:**
    *   Allows modification of a user's information.
*   **Activate/Deactivate a User:**
    *   Users can be enabled or disabled.
*   **Assign Roles to User:**
    *   A dialog allows assigning one or more roles to a user.
*   **Reset User Password:**
    *   A dialog to reset a user's password.
*   **Filter Users:**
    *   Users can be filtered by their active status.
*   **Pagination:**
    *   The user list is paginated.

## 7. Role Management (`/admin/roles`)

This section is for managing user roles and their permissions.

**Screen:** `lib/app/features/roles/views/screens/roles_screen.dart`

### Actions:

*   **List Roles:**
    *   Displays a list of all available roles.
*   **Add a New Role:**
    *   A dialog allows creating a new role and assigning permissions to it.
*   **Edit a Role:**
    *   Allows modification of a role's name, description, and permissions.
*   **Search Roles:**
    *   A search bar allows finding roles by name.
*   **System Roles:**
    *   Some roles are marked as "SYSTEM" roles and are not editable.
